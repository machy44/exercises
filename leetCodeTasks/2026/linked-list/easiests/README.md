# Easiest Linked List Tasks

This folder contains simple linked list tasks to help you understand the basics of linked list operations. Each file contains a specific task with its implementation.

## Tasks

1. **printList.js**: Print all elements in a linked list.
2. **getLength.js**: Find the length of a linked list.
3. **searchValue.js**: Search for a value in a linked list.
4. **insertAtEnd.js**: Insert a node at the end of a linked list.
5. **deleteNode.js**: Delete the first occurrence of a node with a given value.
6. **reverseList.js**: Reverse a linked list.
7. **findMiddle.js**: Find the middle node of a linked list.
8. **hasCycle.js**: Detect a cycle in a linked list.
9. **removeDuplicates.js**: Remove duplicates from a sorted linked list.
10. **mergeTwoLists.js**: Merge two sorted linked lists into one sorted list.

Each file contains a description of the task at the top of the file.
